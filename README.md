# Natural genetic variation shapes pathogen-specific susceptibility to *Pseudomonas* infection in *Caenorhabditis elegans*

Data and R code used to generate the figures, tables and supplementary data in:

> Wan YC, Xiao MA, Mok C, Reinke AW. Natural genetic variation shapes pathogen-specific susceptibility to *Pseudomonas* infection in *Caenorhabditis elegans*. *[Journal]* ([year]). https://doi.org/[DOI]

In this study, 121 *C. elegans* strains were screened in pooled competitive fitness assays (PhenoMIP) against five pathogenic *Pseudomonas* strains, and loci affecting susceptibility were mapped by genome-wide association (GWA), bulk segregant analysis (BSA) and recombinant inbred lines (RILs). This repository starts from the per-sample MIP results files, BSA allele depths and RIL variant calls, and reproduces every figure, table and supplementary data workbook that is generated by code.

## Data

- **MIP results** (`mip_results/`, `minipheno/mip_results/`): one `*.results.txt` per sequenced sample, from the lab's MIP analysis pipeline. `upstream/` and `minipheno/` turn these into strain abundance tables.
- **Strain information**: `final_freezing_plan.csv` (sub-pool and pool of each strain), `good_strains.csv`, `strains_analysed.csv` and `Table S1.csv`; CaeNDR strain data (`20231213_c_elegans_strain_data.csv`), phylogeny (`WI.20231213.hard-filter.isotype.min4.tree`) and divergence metrics from Lee et al. (2021) (`wild_isolate_variants.csv`).
- **Microsporidia PhenoMIP** (`mic_all3data.csv`): z-scores from the companion microsporidia screen (Xiao et al., in prep).
- **BSA** (`BSA_results/<population>/`): allele depths per sample (`<population>_allele_depths.tsv`, and `_columns.tsv` with REF/ALT and sample names), produced from the reads by `BSA_results/BSA_all.slurm`. `BSA_all_populations.R` turns them into the QTLseqr results used by the figures.
- **RILs** (`*_RILs/`): cluster scripts and logs, filtered joint VCFs and VCF-kit hmm output; the copies `*_RILs_joint.filtered.tsv` in the main folder are read by the figure scripts. Phenotypes are in `*_RILs_*_embryos.csv` and `*_gravid.csv`.
- **Single-strain assays**: wild-isolate phenotypes (`JU2610_wild_isolates_*`, `m395_wild_isolates_*`) and FISH measurements (`*_FISH_area.csv`, `*_FISH_body.csv`).
- **GWA** (`gwas/`): NemaScan outputs for the two traits with significant QTL.

Run the four stages in order, each in a fresh R session, from the folder shown:

| Stage | Working directory | Run |

| 2. mini-PhenoMIP abundance table | `minipheno/` | `mini_pheno_remake_strain.average_removebadmips.R`, then `MIPs_graph_miniPheno_260613.R` |
| 3. BSA analysis | repository root | `BSA_all_populations.R` |
| 4. All analyses, figures and tables | repository root | `pheno6_bac_v2.R` |

For example, in R/RStudio:

```r
setwd("upstream");  source("remake_strain.average_removebadmips.R")
source("MIPs_graph_P1bac_261020.R"); source("MIPs_graph_P2bac_261020.R"); source("MIPs_graph_P3bac_261020.R")

```

Figures, intermediate tables and the four workbooks are written to the repository root (the published figures are kept separately in `figures/`). The master script also writes some exploratory outputs that are not in the paper.

## Statistics

Strain fitness was summarised as modified z-scores of the area under each growth curve (AUC) and of the regression slope, relative to the uninfected control. Reproducibility was assessed by linear regression (R²), Pearson's r and Spearman's ρ. Correlations between pathogen conditions used Spearman's ρ with Benjamini–Hochberg (BH) adjustment. Differences between geographic locations were tested with Kruskal–Wallis tests, followed, where significant, by Dunn's test with BH correction; associations with genomic divergence used linear regression. Broad-sense heritability was estimated per pool and condition from a linear mixed model with strain as a random effect (`lme4`). Single-strain assays (embryo number, % gravid, FISH and body size) were analysed on biological-replicate means with Dunnett's test against N2, or against jyIs8 for the JU2250 and EG4946 RILs. GWA significance used NemaScan's eigen-decomposition threshold; BSA G′ significance used a BH false discovery rate of q = 0.01. Exact statistics are in `main_stats_data.xlsx` and `supp_stats_data.xlsx`.

## Notes on reproducibility

- **Dunnett p-values vary slightly between runs.** `DescTools::DunnettTest()` computes adjusted p-values by randomized numerical integration, so reruns give p-values that differ in the fourth decimal place (at most 0.0006 across repeated runs; no comparison crossed p = 0.05). Three comparisons lie close to p = 0.001 and may be shown as `**` or `***` depending on the run: RIL JU4, RIL JU13 and RIL JU24 (% gravid, Supp. Fig. S26B). In the published tables (Stats Data S41) they are p = 0.00107, 0.00101 and 0.00101, respectively (all `**`). Call `set.seed()` before running for identical p-values. Some plots also use `geom_jitter()`, so point positions differ slightly between runs.
- **Detection thresholds** used by `MIP.gc.abundance.R` were set for each dataset from the lowest abundance at which a MIP is detected (start-abundance threshold five times higher): pool 1, 1.362e-05 / 6.81e-05; pool 2, 6.98e-06 / 3.49e-05; pool 3, 0.000449983 / 0.002249915; mini-PhenoMIP, 0.0001 / 0.05. `MIP.gc.abundance.R` contains, unchanged, the part of the lab's `MIP.graph.analysis` script (written by Dr. Calvin Mok, https://github.com/camok) that builds the abundance tables.
- **Strain names.** Strains are named by their CaeNDR isotype (for example, strain ECA259 is referred to as PB306). For NemaScan input, isotype names that are not CaeNDR strain names are replaced by the isotype reference strain (`to_caendr_strain_name()` in `pheno6_bac_v2.R`).
- **Excluded strains.** Eighteen highly divergent strains (listed in `pheno6_bac_v2.R`) and VC20019 are excluded from the PCA and GWA mapping; VC20019, CB4852 and PB306 have no CaeNDR coordinates and are excluded from the geographic and divergence analyses.
- **GWA mapping** was run on the CaeNDR portal (NemaScan, andersenlab/nemascan-nf commit 2593ae0; genotype release 20250625; MAF 0.05; EIGEN threshold with 11,332 independent tests; runs on 2026-10-22) using the input files written by the master script. Each input lists 102 strains, but the portal omitted the first data row of each file, so 101 strains were mapped; rerunning with a different first strain gave identical QTL. Only the two traits with significant QTL (MYb114 AUC, LOCO; MYb395 slope, inbred) are kept in `gwas/`.
- **BSA.** All six populations were processed identically with `BSA_results/BSA_all.slurm` (fastp, BWA-MEM, Picard MarkDuplicates, bcftools; sites with QUAL < 20 or depth < 10 in any sample removed) and analysed with the same QTLseqr settings in `BSA_all_populations.R`. QTLseqr estimates the G′ threshold from each dataset, so the extent of weaker QTL intervals is sensitive to small changes in the input data; strong peaks are not.
- **RILs** were sequenced and called in two batches with identical variant-calling settings. Batch 1 (JU2250, EG4946) files call the lines "NILs"; they are the RILs described in the paper.
